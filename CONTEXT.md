Rules/Style:Strict Separation of Concerns: Agents must have a single job (e.g., routing, planning, synthesizing). No monolithic "do-it-all" prompts.Defensive Parsing: Never trust LLM formatting natively. Always use regex extraction for JSON payloads and strict=False in Python parsers to bypass hallucinated control characters. Explicit Type Safety: Enforce strict Python typing (dict | None) to prevent silent runtime crashes during tool handoffs.
